Conductor

How to run several coding agents at once.

Lunch ’N Learn · Victor Hugo

The problem

One working copy, one task at a time.

Running a second agent in the same folder means conflicting edits, so the rest of the work waits.

What it is

A Mac app that runs coding agents side by side.

Each agent works in its own copy of the repo, so they don’t step on each other.

Worth setting up

Two scripts and new workspaces just run.

# .conductor/settings.toml
[scripts]
setup = "pnpm install"                       # on create
run   = "pnpm dev --port $CONDUCTOR_PORT"    # Run button

Each workspace gets its own port, so you can run several dev servers at once.

Tip · Parallel agents

When to split, and when not to.

Many workspaces

Independent tasks

Separate features, bugs or issues. Each moves and merges on its own.

One workspace

Shared code state

One agent builds while another reviews the same diff.

Trade-offs

Parallel isn’t free.

Review is the new bottleneck

More agents means more diffs and PRs for you to read.

Usage limits drain faster

Parallel agents share one subscription or API budget.

Disk and setup per workspace

Each worktree is a full checkout, plus its own dependency install.

Not a sandbox, Mac only

Workspaces isolate code, not security. The desktop app is macOS only.

Worth knowing

There’s a cloud version too.

Same workflow in remote sandboxes. Out of scope for today.
